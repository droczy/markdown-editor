## Overview

The first beta of Markdown Editor, a native, security-focused Markdown
editor for macOS 26 or later on Apple Silicon. It is meant for the
maintainer's everyday use; it is not notarized (see *Known issues*).

- Plain-text editor and live preview side by side, CommonMark and GitHub
  Flavored Markdown (tables, task lists, strikethrough, autolinks).
- Task checkboxes in the preview can be clicked; ⌘Z undoes the change.
- Links are never opened: a click copies the address and shows the real
  host.
- Works offline: loads nothing from the internet and sends nothing
  anywhere. The preview is locked down in several independent ways, and
  the app runs in the App Sandbox.
- Saves like other Mac apps: autosave in place, earlier versions under
  *File > Revert To*.

[FEATURES.md](https://github.com/droczy/markdown-editor/blob/v0.1.0-beta.1/FEATURES.md)
lists everything the app can do and what is planned; the
[example document](https://github.com/droczy/markdown-editor/blob/v0.1.0-beta.1/docs/example.md)
shows the features in one file to open in the app.

## Known issues

- **macOS refuses the first start.** The app is ad-hoc signed and not
  notarized by Apple. Check the download first (see *Verifying the
  download*), unzip it, move the app to *Applications* and open it. When
  macOS says it cannot verify the app, open *System Settings > Privacy &
  Security*, click *Open Anyway* next to the message about Markdown
  Editor, and confirm. This is needed once per downloaded copy.
- **Links are only copied.** A click on a link copies its address to the
  clipboard instead of opening it. Links to headings in the same document
  (`#section`) and to other files only show a notice.
- **Images are placeholders.** The preview shows the image description in
  place of every image; local images are planned for the next version.
- **Very large documents.** The preview shows a notice instead of
  documents larger than 10 MiB or with an extremely large number of
  elements; the editor keeps working. A file of 50 MB in a single line
  takes about 13 seconds to open.

## Testing

- **CI:** all 12 required checks passed for the last pull request before
  the review (#23) and for the release pull request, and CI passed again
  on `main` (`f8bacc5`): formatting and lints, tests on macOS and
  Linux, line coverage of 99.9 % (threshold 95 %), dependency audit, short
  fuzzing, the macOS app build with its security verification and UI
  tests, the workflow audit (zizmor), and CodeQL for Actions, Rust and
  Swift.
- **Nightly** on `f8bacc5`: 30 minutes of fuzzing (4.3 million inputs)
  without findings; mutation testing with 202 mutants, none missed;
  advisory check of all dependencies.
- **Full security review:**
  [report](https://github.com/droczy/markdown-editor/blob/v0.1.0-beta.1/docs/security/reviews/2026-11-v0.1.0-beta.1.md).
  Two medium findings (SR-2026-004, SR-2026-005), both fixed with
  regression tests before this beta; none is open.
- **Release files:** packaged and verified locally before tagging; the
  release workflow verifies the app again before packaging it.
- **Manual tests:** the maintainer used the app throughout development;
  this beta is for everyday use.
